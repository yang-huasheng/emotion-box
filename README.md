# 情绪盒子 - 治愈系心情日记应用

一个温柔治愈的心情日记应用，结合色彩心理学和人格心理学，为用户提供个性化的情绪治愈体验。

## 项目状态

✅ **完成功能：**

1. 用户系统 - 账号注册登录、隐私密码保护
2. 心情记录 - 18种情绪选择、强度评分、心情面板
3. 日记功能 - 日记编辑、收藏、关键词搜索、历史回顾
4. 放空情绪盒 - 负面情绪记录、定时自动清除、共情安慰
5. 美好收纳盒 - 积极情绪记录、自动分类、专属夸赞
6. 数据可视化 - 情绪分布饼图、心情趋势曲线、热力图、日历视图
7. 人格测试 - MBTI十六型人格、霍格沃茨四大分院
8. AI陪伴 - 根据人格属性差异化回复

## 技术栈

- **前端：** 原生 HTML5 + CSS3 + JavaScript (无框架)
- **存储：** 本地 localStorage + Web Crypto API 加密
- **设计：** 温柔治愈系、响应式布局

## 快速开始

### 方式一：直接打开

直接用浏览器打开 `index.html` 文件即可使用。

### 方式二：本地服务器

使用 Python 3：
```bash
python -m http.server 8080
```

使用 Node.js 的 http-server：
```bash
npm install -g http-server
http-server -p 8080
```

然后在浏览器中访问 `http://localhost:8080`

## 色彩心理学

应用运用色彩心理学，不同情绪对应不同治愈色：

- **正向情绪：** 金色、橙色、粉色 - 提升多巴胺
- **中性情绪：** 蓝色、紫色 - 平静舒缓
- **负面情绪：** 浅蓝、深紫 - 情绪疗愈

## 隐私保护

- 所有数据存储在本地浏览器
- 支持独立隐私密码加密
- 不收集任何用户数据

## 响应式设计

- 手机端：单栏布局，优化触摸操作
- 平板端：自适应网格
- 桌面端：多栏布局，完整功能
